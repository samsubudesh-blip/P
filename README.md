# Моё меню

Адаптивное веб-приложение для планирования семейного питания.

## MVP 0.1
- Учёт продуктов, количества и срока годности
- План меню на 7 или 30 дней
- Каталог рецептов с фотографиями и пошаговым приготовлением
- Расчёт недостающих продуктов для списка покупок
- Локальное сохранение данных в браузере

## Запуск
Откройте `index.html` в браузере или разверните репозиторий через Cloudflare Pages:
- Framework preset: None
- Build command: оставить пустым
- Build output directory: /

## Ограничения первой версии
Фото продуктов пока только загружается для просмотра: автоматическое распознавание состава корзины ещё не подключено. Данные хранятся локально в браузере и пока не синхронизируются между устройствами.
