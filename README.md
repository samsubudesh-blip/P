# Моё меню

Адаптивное веб-приложение для планирования семейного питания.

## Возможности
- Учёт продуктов, количества и срока годности
- План меню на 7 или 30 дней
- Каталог рецептов с фотографиями и пошаговым приготовлением
- Расчёт недостающих продуктов для списка покупок
- Локальное сохранение данных в браузере
- Необязательная синхронизация через Supabase с входом по e-mail

## Развёртывание
Cloudflare Pages:
- Framework preset: None
- Build command: оставить пустым
- Build output directory: /

## Подключение облачной синхронизации

1. Создайте проект в Supabase: https://supabase.com/dashboard
2. Откройте SQL Editor → New query, вставьте содержимое файла `supabase-schema.sql` и выполните запрос.
3. В Project Settings → API скопируйте Project URL и публичный ключ (anon / publishable key). Никогда не используйте `service_role` key в браузере.
4. Откройте сайт «Моё меню», в разделе «Обзор» найдите блок «Синхронизация между устройствами».
5. Введите Project URL, публичный ключ и свой e-mail, затем нажмите «Подключить / войти».
6. Откройте письмо Supabase и перейдите по ссылке входа.
7. На каждом другом устройстве повторите подключение с теми же URL, ключом и e-mail.

Пользовательские данные изолированы политиками Row Level Security: каждый аккаунт может читать и изменять только свою запись.

## Важные ограничения
- Если облако ещё не настроено, приложение продолжает работать локально.
- При первом входе на устройстве, где облачная запись ещё не создана, текущие локальные данные загружаются в облако. На следующем устройстве данные из облака заменят локальный набор этого браузера.
- Для входа по e-mail в настройках Supabase должен быть включён Email OTP / Magic Link.
- Распознавание продуктов по фотографии пока не подключено.
- Генератор меню и расчёт покупок пока являются базовой версией и требуют дальнейшего тестирования.
